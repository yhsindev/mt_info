# 山行卡

2026-10-26：第一版已實作，入口為 [`/cards.html`](http://127.0.0.1:5173/cards.html)。這是獨立 Vite／React 入口，不載入地圖元件或查詢資料 API；既有首頁與 `cards.html` 都會進入正式編譯結果。研究與取捨見[原始可行性草案](research/FIELD_CARDS_2026-10-26.md)。

## 畫面與操作

- 首頁可開始 6 題山行情境測驗，或直接抽取山景卡。測驗一次一題，可返回改答，沒有作答時不能前進；4 種結果為觀察派、探索派、紀錄派、營地派。
- 得分只依有效的 6 題作答計算；平手依觀察、探索、紀錄、營地的固定順序處理，並非能力排序。測驗答案與結果只在目前頁面記憶體，不存到圖鑑或送出。
- 山景卡獨立隨機抽取，8 張各為 1/8：稜線、雲海、森林、溪谷、營地、星空、湖泊、晨光。使用瀏覽器 crypto 取得一個 byte，256 可被 8 整除，不因取餘數產生機率偏差。這不是山岳完登或實際行程紀錄。
- 卡面及卡背可翻轉。首次按「加入圖鑑」才記錄收藏；同一次揭曉無法連按增加次數，再次抽中同卡才會累加，圖鑑卡片不重複列出。
- 桌機以內容／卡片並排；手機測驗不顯示裝飾卡面，結果頁先看卡片，再看收藏和匯出控制。正文至少 16px、註記 14px、主要點擊高度至少 48px，支援鍵盤與減少動效設定。

## 入口與計畫保留

桌機主站頁首右側提供「山行卡」連結；手機放在「更多」的 disclosure，沒有新增第六個主要工具按鈕。可 Tab 進入連結、Esc 關閉回焦、外點關閉；同一入口也提供資料來源。

普通左鍵由計畫通前往山行卡時，先執行既有離頁守門並保存最新草稿；失敗時仍留在計畫並可取消。返回連結只帶目前 layer、plan、已知 rain 產品；山行卡再核對根路徑與允許值，不接受任意外部 return URL。修飾鍵仍保留瀏覽器原生開分頁行為。

這是實際換頁，原本只留在記憶體的本機 GPX 不會隨返回重新載入。草稿仍依既有格式保存，沒有把 GPX、設備、氣象或定位寫進收藏。

## 休息站與離線

山行卡內新增「休息站」，不佔主工具的第六個導覽位置。九格山路觀察賓果從 18 個原創短句抽取，點選三格連成橫、豎或斜線即完成；「換一局」重新抽取。這只是休息時的遊戲，不以行程安全或能力作評分。進度存於獨立的 `mt-info-rest-bingo-v1` 本機鍵值，讀取時驗證題目 ID 與已點格子，儲存失敗則僅保留當次畫面。

正式建置使用 Vite manifest 找出 `cards.html` 相依的 JS、CSS 與品牌 SVG，產生僅控制 `/cards.html` 的 Service Worker。先連線開啟一次，安裝完成後可離線重開卡頁；主工具、圖資、API 和外部山歌頁面都不在這份快取內。開發伺服器不註冊此 Worker；瀏覽器若清除網站資料或回收快取，必須重新連線載入。圖鑑與賓果均在瀏覽器本機，不會跨裝置同步。

山歌目前只有歌名、來源版本說明及原頁連結，不能在離線時開啟原頁。完整歌詞、曲譜、錄音與歌本輸出需逐版本確認權利與授權；查核欄位與來源見[山歌來源清冊](SONG_INDEX.md)。

## 收藏與備份

`localStorage` key 為 `mt-info-cards-v1`，與計畫的 `mt-info-plan-v1` 分開。schemaVersion 1 僅保存卡片 ID、卡面版本、首次／最後取得 UTC 時間與次數；重複取得遇裝置時鐘倒退時保留較晚的最後時間。

備份 JSON 上限 32 KiB、最多 8 張，逐筆檢查已知 ID、唯一性、正整數次數、卡面版本、合法時間及前後順序。匯入剔除無關欄位，不還原題目答案或任意程式內容。確認取代前不寫入；無效匯入、取消、寫入失敗均保留現在的收藏。

儲存失敗會顯示尚未保存，記憶體收藏仍可備份；普通返回工具需再次確認，重新整理有 beforeunload 提示。本機原圖鑑損毀時不自動覆寫，提供原始內容備份及明確重建／還原；重建不會清掉其他儲存鍵。收藏不跨裝置同步；換網域、協定或連接埠後需自行匯入備份。多個分頁同時編輯尚未提供合併協調。

## 圖像與輸出

8 種向量構圖由本站程式原創繪製，不下載外站圖片、字型、圖磚或山友照片。SVG 僅使用 path、形狀與文字；動態文字做 XML escape，色值受限，不使用 foreignObject 或外部資源。畫面與匯出共用目錄及藝術圖像，排版依用途調整。

| 輸出 | 規格 |
| --- | --- |
| 分享卡 PNG／SVG | 800×1120px |
| 書籤 PNG | 591×1772px |
| 書籤 SVG | 50×150mm、viewBox 500×1500 |
| A4 裁切列印 | 單面 50×150mm，四角 8 段裁切線 |

PNG 由同來源 SVG 在裝置端轉換；若無法使用 Canvas／轉換失敗，改提供 SVG 並顯示實際格式，不能假稱取得 PNG。暫存 URL 會回收。A4 使用瀏覽器列印／另存 PDF；請選實際尺寸／100% 並關閉頁首頁尾。PNG 的像素尺寸不保證實體列印尺寸，雙面對位與印刷廠出血規格尚未提供。

SVG／PNG／列印使用本機可用中文字型替代，沒有內嵌或轉外框字型；不同系統排版可能略有差異。這輪已在 Chrome 核對 8×2 份 SVG 文字框無越界及實際輸出，仍需真機及紙本列印確認。

## 檔案與驗證

- `src/cards/catalog.ts`：題目、結果、卡片文字及版本。
- `src/cards/model.ts`、`storage.ts`：計分、抽取、去重與備份解析。
- `src/cards/artwork.ts`、`export.ts`：原創幾何藝術及獨立輸出。
- `src/cards/CardsApp.tsx`、`cards.css`：同頁測驗／結果／圖鑑／休息站，`navigation.ts` 核對回程參數。
- `src/cards/RestStop.tsx`、`bingo.ts`、`rest.css`：賓果、山歌索引與休息站介面；`offline.ts` 與 `scripts/build-cards-offline.mjs` 建立卡頁離線快取。
- 單元測試為 `tests/cards-*.test.ts`；隔離 Chrome 為 `tests/ui/cards-qa.cjs ui`、`tests/ui/cards-qa.cjs exports` 及 `tests/ui/cards-header-qa.cjs`，需環境提供 Playwright／Chrome。

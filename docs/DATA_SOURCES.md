### 日期與座標如何處理

- `publishedAt`：來源明確的發布日期。CSV 不提供每筆發布時間，保持 null；HTTP `Last-Modified` 另存為快照 `sourceModifiedAt`，不當成設備巡檢日或逐筆發布日。
- `fetchedAt`：實際成功取得資料的時間。種子為本輪查閱來源的時間，不表示現場查核。
- `checkedAt`：設備確切實際巡檢時間。未知保持 null。雪霸公告只給一段巡檢期間，保留於 `checkNote`，不把區間末日填成每台的巡檢日。
- AED ID `3837` 的 CSV 座標（24.266667, 121.15）與所載武陵露營管理中心有明顯疑義；保留原值於來源快照，清單說明、暫不畫點，未自行猜測修正座標。
- 三六九臨時營地不以三六九山莊舊址代替；觀高新山屋也不以已關閉的舊觀高工作站代替。
- CSV 未提供獨立的設備管理單位，`manager` 保持 null，不能把資料提供機關或場所名稱自動改寫成管理單位。來源時段、休館限制及聯絡欄照原值保留，不將異常欄位推測修正為開放承諾。

### 同步與資料品質

`scripts/sync-data.ts` 與後端背景排程共用固定衛福部端點、下載鎖及驗證流程，檢查表頭、CSV 欄寬、有效識別碼、合理全國筆數及非空相容區域結果，再將全國／區域輸出寫入同一版本目錄，回讀驗證後原子切換 manifest。下載或驗證失敗時不切換原成功版。它處理 UTF-8 BOM、引號內逗號／換行；缺座標不會變成 0。來源場所名稱缺漏時保留未知值；缺 ID 列不進入名錄，整份無有效 ID 則拒絕更新。快照附來源檔名、HTTP 檔案修改時間、抓取時間及原始 CSV SHA-256，不保存回應 cookies。

全國快照以共用 `columns` 與 `rows` 保留 adapter 需要的官方原始欄位，省略未使用的場所分類／介紹；約 4.7 MB。伺服器只在首次使用／revision 改變時轉成 Equipment 模型，依全臺或舊區域重用陣列，HTTP JSON／gzip 也依 revision、範圍、抓取時間及時效狀態快取並限制大小，不逐請求重建約 1.6 萬筆。`GET /api/equipment` 預設全臺，`?region=xueshan|daba` 保留相容；回應仍為 `{items,status,fetchedAt,message}`，設備可選附 `address`。支援 gzip、ETag／304、`Vary: Accept-Encoding`，公開快取 60 秒；初始完整 JSON 約 14.43 MB，gzip 約 1.54 MB。CLI 同機切換 manifest 後 API 熱載入，不需重啟；前端主動查詢使用 `cache: no-cache` 重新驗證，避免剛換版時重讀瀏覽器的舊 JSON。瀏覽器的可選設備保存可能受容量限制，不能承諾全國名錄離線可用。

本機 AED 保存逾 48 小時標示 stale，仍可閱讀原資料與抓取時間。48 小時為本工具顯示門檻，不是官方設備保證。PAC 歷史資訊的查核說明始終保留。每日背景同步、5 分鐘起指數退避、持久最後成功版本及同步狀態已完成；仍未建立管理單位回報機制。設定、時間語意與部署限制見 [自動更新說明](./AUTO_UPDATE.md)。

本環境 Node 24 需使用系統憑證庫才可驗證衛福部完整憑證鏈；可用 `node --use-system-ca --import tsx scripts/sync-data.ts`。TLS 驗證保持啟用，不設定 `NODE_TLS_REJECT_UNAUTHORIZED=0`。其他主機應依其受信任憑證配置處理。

MVT 是切片與簡化的顯示多邊形，跨圖磚可能重複或裁切。點選只表示所選官方既有子集水區，不能當指定渡溪點的完整上游範圍，也不能拿來計算精密面積、匯流或進行雨量面積加權。目前只可同圖對照所選地區測站，沒有將站值假稱為流域平均雨量。圖磚無法載入時仍保留清單、文字與來源狀態。

本工具不將雨量、流域或設備名錄轉成「安全渡溪」「安全登山」、診斷治療或可飲用水源結論，亦不表示來源機關推薦本產品。

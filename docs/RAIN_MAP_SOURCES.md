# 彩色雨量圖：參考研究、來源與限制

查核日期：2026-10-15（臺灣時間）。本輪以直接在 `mt_info` 閱讀官方雨量圖為實作方向；可縮放的官方圖表與具有精確座標的地圖圖層分開說明。資料來源、圖表發布時間與本機抓取時間不互相代替。

## 本機實作狀態

- `GET /api/rain-maps` 回傳已核對的固定圖表目錄，包含 6 小時 8 張、12 小時 4 張及 MPAS 官方原頁瀏覽項目；不要求 CWA 金鑰，也不代替使用者向官方抓取全部圖表。
- 前端在「雨量與預報 → 全臺雨量圖」同頁載入所選的官方 PNG，提供時段選擇、上一張／下一張、播放、縮放與返回全圖。圖片載入失敗時提供重試，不改用示範數字或零雨量。
- `available` 只表示固定目錄已設定；「圖面已載入」只表示該圖片載入成功。它們都不表示預報已通過時效檢查。目錄查核日不是預報發布日。
- 每張圖的 `validFrom`、`validTo` 及產品 `issuedAt` 保持 null，依完整原圖顯示發布與有效時間，並明示目前無法自動核對過期。圖檔快取參數只用於重新取得圖片，不能改標成資料發布時間。
- 全臺圖表不隨雪山／大霸選區裁成山區數值圖，也不輸出地點精確雨量、像素估值或插值。原有測站、登山預報與 QPESUMS adapter 保持獨立；缺金鑰與待核對格點狀態仍如實顯示。
- 2026-10-22 已啟用 MPAS 官方原頁瀏覽，`display=official-page`、固定 `pageUrl`、`frames=[]`；雙週數值 API 仍未啟用，不轉存圖片。雨量圖不主動保存為離線資料包，重新連線或切換圖面仍需官方服務可用。

## 參考網站實際如何運作

參考：[rain-predit](https://ben901227.github.io/rain-predit/)、[公開程式庫](https://github.com/Ben901227/rain-predit)。本輪讀取公開 GitHub 檔案與 API，核對版本為 [`d44a5b671b3e7b16ee9074d3af44f3ecf9dcc822`](https://github.com/Ben901227/rain-predit/tree/d44a5b671b3e7b16ee9074d3af44f3ecf9dcc822)（2026-08-30）。

- `qpf.js`、`rain_grid.py` 使用氣象署 6／12 小時 PNG 圖表；沒有 NCDR MPAS 介接。
- 圖表透過氣象署顯示；位置讀值則來自部署時自行解析圖片色階、產生的 RLE 像素網格，並非氣象署原始數值格點 API。
- `calibrate.py` 用縣市邊界擬合經緯度與圖像像素位置；此為該專案的校正方法，不是官方公布的地理配準。圖框、離島插圖、圖例及標誌會影響像素判讀。
- 可參考的查詢流程是選地點、切換 6／12 小時、沿時間軸比較、縮放／回到全臺，同時看原圖的發布／有效時間與圖例。`mt_info` 採獨立元件實作，不下載該站生成的 `rain/*.json` 作產品資料源。

上述兩張 PNG 僅有 IHDR／IDAT／IEND 區塊，未提供可直接解析的 tEXt／iTXt／zTXt／tIME 時間資訊。6 小時圖片 HTTP `Last-Modified=2026-10-14T15:14:39Z`（臺灣 23:14:39），與圖上發布 23:30 不同，因此只能標成**檔案修改時間**。本機抓取成功時間另存；發布時間與有效時間若無可信結構資料，保持未知並明列「以原圖標示為準」。

官方頁面的 `/Data/js/fcst/QPF_TIME.js` 用於產品顯示控制，不應把其布林旗標當發布時間；`GetDataTime('M')` 為頁面圖片更新／快取參數，也不代表預報發布時間。不得依目前時鐘、檔名尾碼或 HTTP 標頭拼湊一組看似精確的有效時段。

## 在工具內呈現的界線

第一階段可在同頁提供官方圖表、6／12 小時切換、時段選擇、縮放及完整圖例；不需要使用者跳轉官方網站才能看到圖。官方原頁連結仍保留作來源查核。

這些 PNG 是帶標題、圖例、機關圖樣與離島插圖的完整圖表，沒有 world file 或正式圖磚座標規格。直接把整張圖片的四角對到臺灣經緯度、疊在 OSM 底圖上，會使圖框與離島位置錯置。第一階段因此應稱「官方預報圖表」，不能假稱為已完成精確定位的雨量格點圖層，也不從顏色自行讀出某一山屋的精確雨量。

若後續做參考站類似的像素判讀，需另驗證投影、圖版變動、色階與遮蔽區、誤差及時間版本一致性；只能表達可辨識的級距。不得用周圍顏色補成官方未提供的地點預報值。優先方向仍是取得正式數值格點及座標規格。

下載失敗、非圖片、上游超時、某時段不存在時要顯示來源失敗／未提供；不能替換為空白圖、零雨量或示範圖。若保存舊圖，須顯示保存時間，且不因 HTTP 最近抓取成功便宣稱預報仍有效。圖表上發布／有效時間、毫米單位與色階不得被介面永久裁掉。

## 授權與穩定性

[氣象署網站資訊使用聲明](https://www.cwa.gov.tw/V8/C/information.html)允許在註明出處前提下再利用網站資料素材，另列第三人著作、商標及機關標誌等例外。本工具保留官方圖表原貌與來源顯名，不將圖內標誌另作產品品牌，亦不表示氣象署認可本工具。

同份聲明「連結至本署網站」第 2 點說明檔名、位置、格式會異動，**不建議連結特定檔案或採自動擷取**。因此以上圖片是經官方頁面驗證的公開顯示資源，不能稱為有版本／服務承諾的正式開放 API。實作應採固定來源白名單、共用快取、有限重試與明確失敗狀態，避免每位訪客重抓全部圖表；正式長期服務仍優先改接氣象資料開放平臺的正式產品。

本文件僅處理來源與呈現方式；資料再利用授權不等於自行研判發布氣象預報的業務資格。工具保留官方原圖、原始產品與時段，不混合模型產生自家預報。

## MPAS 官方原頁瀏覽與數值格點限制

[NCDR 颱洪降雨頁](https://watch.ncdr.nat.gov.tw/watch_tfrain_fst)包含多種不同預報；[MPAS 雙週頁](https://watch.ncdr.nat.gov.tw/watch_mpas2weeks)明列 60–15 km 可變網格及實驗性質。[WATCH 使用說明](https://watch.ncdr.nat.gov.tw/watch_user)指出產品用於特定防災研究，且轉貼圖文須經允許。不能因參考網站使用氣象署圖片，就推定 NCDR MPAS 也有相同授權。

[NCDR 正式開放申請入口](https://watch.ncdr.nat.gov.tw/watch_api_open)、[Token／API 說明](https://datahub.ncdr.nat.gov.tw/paradigm)可確認有申請介接流程；已公開的 [15 km 系集雨量](https://datahub.ncdr.nat.gov.tw/dataset/detail?pid=bce5a299-986b-4d26-80e7-eaa414996e4e)為 84 小時產品，不能當成 MPAS 雙週格點。MPAS 雙週的正式資料產品編號、公開展示範圍、原始格點或 WMS／XYZ、座標及累積時段，本輪仍未核實，不使用其內部查詢端點或其他站的轉存資源。

氣象署 QPF 正式數值格點、QPESUMS 未來一小時、上述官方 6／12 小時圖表也是不同產品；取得其中一項授權碼或圖片，不代表其他項已完成介接。下一階段按具體產品逐項核對正式下載規格、時段、座標與公開使用條件。

### 2026-10-22 同頁官方畫面

本輪改以固定的[官方雙週頁](https://watch.ncdr.nat.gov.tw/watch_mpas2weeks) iframe 直接瀏覽；沒有圖片代理、複製／解析 GIF 或調用內部清單。原站預設臺灣本島，已實際驗證可嵌入；HTTP 未送 X-Frame-Options，CSP 未設 frame-ancestors。這是本輪技術觀察，不是圖文轉載授權。頁尾引用文字與詳細使用說明第六點仍並存，因此不宣稱取得自行轉貼／再授權圖文的許可。

原頁「模擬時間 UTC」是模式初始時間，不能當發布時間；原圖日期與累積起訖保留原貌，不由目前時鐘推算。`issuedAt`、累積小時、完整預報時數維持未知，`timeStatus=on-page`。當前官方顯示 15 個日圖；「雙週」是產品名稱，不硬編碼為必定 14 張或 336 小時。只在選此產品時開啟 iframe，離開即移除，不增設背景更新排程。

手機原頁固定約 1150 px 寬，原始大小可捲動，符合寬度是整頁縮小概覽，沒有裁掉標頭、圖例或說明。外層保留實驗產品、UTC 換算及原站入口；16 秒仍在等待會提示較慢。跨來源 iframe 的 load 事件不代表內部圖表成功，故不標示雨量已更新或圖面已取得，不擷取跨來源 DOM 驗證資料。離線不新開 iframe，已開啟畫面保留並提示無法確認更新。未建立離線圖包或全臺數值格點。

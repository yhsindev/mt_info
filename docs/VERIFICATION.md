## 執行方式

```sh
npm test
npm run build
npm run dev
```

瀏覽器檢查使用 Codex 內建瀏覽器，最後的手機相機範圍回歸另使用已連線的 Chrome；目標為 `http://127.0.0.1:5173`。手機與桌面尺寸分別以 390×844、1280×800 視窗驗證。

另有僅供本機驗證的故障預覽，需先執行 `npm run build`，並維持正常 API 在 8787 埠運行：

```sh
node tests/ui/fault-preview.mjs --mode=slow --port=5180
node tests/ui/fault-preview.mjs --mode=unavailable --port=5181
node tests/ui/fault-preview.mjs --mode=map-unavailable --port=5182
node tests/ui/fault-preview.mjs --mode=timeout --port=5183
node tests/ui/fault-preview.mjs --mode=cache-failure --port=5184
```

`slow` 將每個 API 回應延後 2.5 秒；`unavailable` 對 API 回覆 503；`map-unavailable` 以更嚴格的預覽 CSP 阻擋外部地圖連線；`timeout` 延後 18 秒以超過前端 16 秒逾時；`cache-failure` 第一次設備請求成功，重新整理後改回 503，以驗證已保存資料。這些是測試條件，不改變產品程式與作業系統網路。它們不等同完整離線、限速頻寬或手機無線網路。

無私人授權碼時，不能據此聲稱氣象署授權產品已實際成功串接。瀏覽器尺寸驗證也不能代替 iOS／Android 真機、系統定位權限及行動網路測試。

本機沙箱預設禁止監聽 localhost，Supertest 的初次執行因此得到 `listen EPERM`。允許該次測試的 loopback 監聽後重跑，28 個測試全數通過；這項環境限制不屬於產品測試失敗。

## 驗證中修正的問題

- MapLibre 6 將 Worker 分成獨立模組，預設相對路徑在 Vite 重新打包後找不到。改成明確的 Vite `?url` 資產，開發與正式編譯回歸均可載入官方向量圖磚、選取屬性，正式預覽沒有新的瀏覽器錯誤。
- 手機選中標記曾蓋過資料卡；加入地圖堆疊隔離。密集 AED 標記改成可展開清單的群組。
- 圖層切換原本保留上一層捲動位置；現在回到清單頂端。來源視窗改為原生 dialog，示範資料不再連到不存在的「官方來源」頁。
- 舊資料頁持續開啟會重新檢查時效，包含背景更新失敗；預報依原始因子區間選取，不把逐小時氣溫的游標套成降雨機率的新起訖。

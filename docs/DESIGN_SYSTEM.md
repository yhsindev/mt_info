# 介面閱讀與設計規範

2026-10-22 依使用者提供的設計建議精修，保留森林綠、暖白、細線、黑色大標與原有工具架構。最初統一放大後，依實際回饋改成桌機與手機兩套閱讀比例；手機減少標題佔比，保留可讀內文及較大的觸控範圍。2026-10-26 再依密度回饋收緊桌機字級、頁首與卡片間距；手機內文保留 16px、註記 14px。雨量原圖、色階、時間放大及操作保持原樣。

底圖供應者的地名字形、MapLibre 原生控制／顯名，以及官方雨量圖片或原頁內的字，不由本站重繪。一般單行輸入框可在框內橫向捲動編輯；公告、來源網址及展示文字則須在窄螢幕換行。來源視窗的長標題使用平衡換行，保留大字並避免窄螢幕只剩一個字獨佔一行。

## 本輪實際調整

- **急救**：桌機地圖側欄統一為 420px，中等寬度為 380px。手機面板依內容高度測量，地圖 padding、清單切換與顯名位置跟著調整。聚合只顯示數量，單一設備保留設備圖示，三類設備仍分開聚合，全部資料及原始位置不變。卡片持續區分衛福部名錄與官方公告種子，不把登錄或巡檢改成現在可用。
- **集水區**：移除原本會切去設備搜尋的輸入框，未新增不存在的集水區搜尋。保留放大／點選指引，選取範圍增加明確描邊並與原卡片同步；MVT、來源、年份和水文限制不變。
- **路況**：搜尋及篩選移到統計之後、分區之前，跨區單計另有短說明。發布日期與來源封閉起日分開；只有合法的來源 `closureDate` 可以標示未來的「預定封閉／預定限制」，不從標題猜日期，也不因預計開放日過去而解封。臺北曆日變更會刷新提示，只有日期時不補生效時刻。這是展示層，不改來源狀態與統計。
- **計畫通**：主要流程標為選擇路線、編輯計畫、儲存／匯出；第三步直接跳到同頁匯出區，保留現稿。空白與檔案起始方式收進可展開區塊，範本的主要操作保留。日期列收為 48px，桌機行程／地圖約 42／58，主工作區加高至至少 520px，三個次要設定區往下捲才出現。右側固定地圖，移除地圖／路點圖切換列；GPX 匯入置於圖內，原行程示意僅保留圖檔匯出。時序預設只顯示路點、移動時間與距離，點選後才展開編輯；休息按需加入。桌機行程清單獨立捲動，手機保留自然頁面捲動與原有 420px 圖面高度。
- **品牌**：使用者選定 C 方向後，以幾何精修版替換頁首符號及 favicon，保留既有 Georgia 字標。柔和／幾何／極簡三款 C 精修於 `/brand-refinement.html` 比較，先前 A／B／C 保留為歷史提案；見 [BRAND_STUDY.md](BRAND_STUDY.md)。本輪未做商標或完整近似檢索。

本輪沒有修改 API、設備／流域資料、原始路線參考、計算規則或正式部署設定。新建範本的使用者休息安排預設為 0；原始大霸參考、舊稿與匯入檔的未知值不改寫。既有樣式仍有歷史規則；新增元件應使用 tokens，維護舊頁時注意 selector specificity，不能只改一處字級後假設手機已套用。

## 驗證方式

以隔離 Chrome、相同 1440×1000、390×844、360×640 視窗比對，檢查 computed 字級、正常文字對比、觸控範圍、展示文字裁切、長網址、頁面橫溢、捲動、鍵盤焦點、未來公告日期與既有雨量圖操作。品牌頁另外檢查 320px 寬度及實際 16／32px 圖示。執行記錄與具體限制見 [VERIFICATION.md](VERIFICATION.md)。

以上為桌機 Chrome 的視窗及受控行為檢查，並非 iOS／Android 真機驗收。Logo 已依使用者要求套用；公開部署與之後的品牌命名尚未執行。

## 山行卡（2026-10-26）

獨立頁沿用 Georgia 字標、森林綠、暖白與 16／14px 手機閱讀比例，卡面為原創 SVG 幾何山景。桌機左右並排、手機結果先顯卡面再顯收藏操作；測驗一次一題，主要控制 48px。只使用有限次 CSS 翻牌，支援 prefers-reduced-motion。桌機頁首右側新增次要連結，手機以「更多」保留五個工具入口；來源視窗從更多開啟仍能正確回焦。詳見 [FIELD_CARDS.md](FIELD_CARDS.md)。

## 計畫通路線庫精修（2026-11-17）

本輪只整理路線庫的展示層，沿用森林綠、暖白、現有字體、共用 tokens 與 React 架構。標題改為「路線庫」，檢視切換與搜尋／分類／山脈分層；結果數放在清單前，篩選有結果時可直接清除。手機減少外框與重複標籤，保留 48px 以上控制。

路線卡片區分類別、參考數字、資料收錄與套用操作；查核時間直接顯示在概覽，仍稱「資料查核」，不改稱現地觀測或即時更新。資源卡收合時可讀來源名稱；來源發布、現地觀測、資料查核與使用限制仍各自列出。分日待核的五條路線保持停用，文字不再隨整個按鈕淡化。

正文與完整限制說明至少 16px；來源、日期、標籤至少 14px。山友軌跡來源標題取消兩行裁切，來源連結文字可獨立換行；窄卡片的資源欄位改為標籤在上、內容在下。動態僅作操作回饋，減少動態時不位移。

未變更路線資料、座標、GPX、分日、計算、草稿保存、匯入或匯出邏輯。taste-skill 原始檔保持不動；行銷網站的滿屏 hero、裝飾動態與每屏一節規則不套進查詢工具。實際檢查與比較見 [本輪驗證記錄](ROUTE_LIBRARY_POLISH_2026-11-17.md)。

## 跨工具字級與載入整理（2026-11-17，第二輪）

同樣用途的文字跨工具共用閱讀角色：頁面大標桌機 36px／手機 30px，區塊標題 26px／24px，卡片標題 20px／19px，正文與輸入 16px，來源／日期／標籤至少 14px，主要控制至少 48px。計畫通主標改回 `--text-page`／`--text-page-mobile`，手機主要流程按鈕使用 `--text-control`；編輯器為工作區保留較緊湊的日程與欄位標題。

雨量圖原本被共用閱讀選擇器排除，本站控制與說明仍使用 7–12px；MPAS 外層說明使用 12–13px。本輪以 `RainMap.css` 統一本站字級、來源換行與控制高度，觀測／短時資料的文字也同步整理。手機維持圖面在前、詳細控制在後，縮放與播放定位於圖面區域，原圖時間區域在載入完成前保留尺寸並停用操作。官方圖片、色階、時間標示、iframe 原頁字級與顯示大小算法不重繪、不解析成本站數值。

主工具與山行卡加入「略過導覽」鍵盤入口，地圖畫布保留清楚的鍵盤焦點。主地圖與行程對照圖改按需載入，路線庫／路況／雨量頁不再預載 MapLibre CSS。字體沿用 Noto Sans TC 與 Georgia 字標，以官方可變字重範圍 `400..750` 取代八組重複宣告；字型檔 URL 相同，字體 CSS 減量，字型檔容量另行量測。

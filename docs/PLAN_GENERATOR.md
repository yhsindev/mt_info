# 登山計畫產生器

2026-10-26 更新：計畫通改為逐日行程工作區，佔滿工具內容區。桌機左側閱讀逐日路點、點選才展開分段編輯，右側固定顯示地圖，移除原本的地圖／路點圖切換列；手機切換「行程／地圖」，進入編輯時直接定位到日期與行程區，上方設定仍可往上捲查看。沿用森林綠、暖白與 Georgia 字標，不使用浮動側欄。上方仍可切換急救、雨量、集水區、路況與計畫通；「儲存／匯出」跳到同頁匯出區。返回工具或切換頂部入口時先保存草稿，保存失敗仍提供備份及明確離開確認。

## 草稿與來源

可從 23 條百岳／多日中級山路線索引查找，其中 18 條可建立草稿；雪山西稜、大小劍、志佳陽上雪山、屏風山及八大秀的現有分日待核，暫停套用。先前建立且**路線名稱完全相同**的草稿仍可編輯，編輯頁會顯示審查提醒；北大武與白姑舊兩日草稿須手動重排成三日，不覆寫原稿。範本以山脈、分類及關鍵字交集篩選；中級山為松蘿湖、加羅湖、水漾森林兩日框架。雪山西稜雖有官方六日分類，四日山友 GPX 不能替代六日分日。天數及每日切分可編輯，不宣稱為當天可成行的官方建議。名錄包含 33 筆水源記錄、27 筆山屋、25 筆營地／宿營紀錄，詳見 [PLAN_CATALOG.md](PLAN_CATALOG.md)。GPX 仍只在瀏覽器記憶體保存；計畫只使用其名稱，不將軌跡上傳、寫入草稿或推估距離／爬升。自訂 GPX 不套用大霸的住宿、水源或撤退資訊。

大霸種子來自林業署[大霸尖山登山步道頁](https://recreation.forest.gov.tw/Trail/RT?tr_id=027)，2026-10-21 核對，保存分段距離與時間及原文來源。官方摘要與分段加總有差異，逐日備註記錄差異；不補造休息以吻合摘要，也不把參考時間當作隊伍配速。來源再利用及測製日期限制承接[官方步道清冊](TRAIL_GEOMETRY.md)。

目前官方路況仍使用既有後端資料服務與時效門檻。只有範本帶有可確認的林業署步道 ID 時，才對應該 ID 的已收錄公告，目前為大霸 `027`、嘉明湖 `139`、北大武 `119` 與奇萊南華接近路段 `064`；國家公園或中級山路線不藉名稱猜配林業署 ID。顯示來源狀態及查核時間；使用者可明確附入計畫，保存該次文字快照與時間。雪霸查核時的公告另以日期快照顯示，不冒充即時狀態。匯出後的快照不會自動更新，行前仍需重新查看。未附入公告不表示無風險，也不由幾何相交自動宣稱任意公告適用。

使用者提供的 Word 範本只參考欄位結構：逐日行程、主備水源、住宿、撤退、留守、菜單及裝備。原範本中的姓名、電話、歷史水況、醫療指示與第三方地圖圖片不進入示範資料。

## 編輯與計算

編輯頁一次安排一天，48px 日期分頁保留各日選定路段；首次進入沒有預先展開的路段。連續路段的共同路點只顯示一次，路點之間列移動時間與距離。點選才展開移動時間編輯，休息按需加入／移除；起終點、距離、負重、升降與來源再展開。桌機行程／地圖約 42／58，行程在固定高度區域內獨立捲動，手機保留自然頁面捲動。當日水源、過夜及撤退狀態有短摘要，完整欄位收進當日展開區；隊伍、留守、裝備、來源與待確認事項另放在同頁下方。資料仍以日／路段為單位，不把每日水源憑名稱猜配到特定地圖點。

大霸原始參考分鐘只在步道 ID、路段 ID、起終名稱及來源均仍符合既有種子時獨立顯示。新增八條路線目前保留 42 筆符合方向與起終名稱的分段參考；雪山西稜及八大秀的編輯來源分鐘經分日審查已撤出預填。反向、合併、拆分或找不到數值的路段保持未知。修改本隊分鐘不會改寫參考，改路線名稱、起終點或來源後不再套用。參考標籤顯示來源單位，匯出備註保留查閱日與原文；不以「上河時間」統稱。本輪不變更 schemaVersion 1，也不把舊稿已編輯的分鐘重新認定成未改過的原始參考。

範本來源、官方開放狀態／山屋營地／申請入口集中在同頁展開區；這些是已核對用途的連結，並非已取得即時床位或許可。開啟範本目錄本身不會自動建立或覆寫本機草稿，必須明確使用範本／建立空白或開始輸入。

每一天可增刪路段，填起訖、移動／休息分鐘、距離、爬升／下降、重裝／輕裝及來源。時程依出發時間逐段加總，跨午夜保留次日標記；遇到未填時間就保留後續時間未知。日期採曆日加減，不受瀏覽器時區轉換影響。

`null`／空白表示未知，`0` 表示明確不安排休息或零值。新建範本的使用者休息安排為 `0`，按「加入休息」後先成為待填 `null`，輸入分鐘才參與完整時程；移除休息回到 `0`。原始大霸來源種子仍保留未知，既有與匯入草稿的 `null`／`0`／正值不自動改寫；當日「設為不安排休息」需使用者明確操作，且只修改尚未填的休息。距離、爬升、下降、時間及用水若不完整，只能列已填小計及未知筆數。路段時間由使用者確認，不從直線距離換算。

每日用水依使用者輸入計算：人數 × 每人用水 ＋ 全隊炊事水 ＋ 全隊備用水。任一項未填就不顯示完整需求量；這不是建議飲水量或足夠用水判定。取水繞行分鐘另作備註，必須自行編入行程路段，避免默默重複計算。

水源保留主備取水點、回報日期、來源及未知／曾回報／已人工確認／乾涸狀態。住宿保留主備案、申請／核准狀態及核准紀錄，不查詢即時空床。撤退保留決策點、截止時間、觸發條件、路線與人工核對；不依最近出口自動選路。待確認清單提示資料完整度及時程矛盾，不給安全分數或可成行結論。

## 地圖與路點

大霸可用固定 `GET /api/plan-route/027` 取得官方步道參考線段；北大武可用 `GET /api/plan-route/119` 取得官方三段參考線。大霸 KMZ 有 131 個線點且不含觀霧至馬達拉溪約 19 公里林道；北大武來源線也不含新登山口至舊登山口的接近路段，兩者都不是完整計畫軌跡。端點只接受固定 ID、拒絕 query 與任意 URL，不新增外部代理或即時下載。資料保留來源、顯名與查閱日，實際測製日未知；有線不代表目前開放或已巡檢。沒有來源幾何的範本仍顯示地圖，若也沒有已定位路點則先顯示臺灣全圖，並明示未收錄軌跡，可在圖內左上角匯入 GPX。不再用順序示意取代地圖。軌跡來源失敗但已有路點時，仍顯示來源失敗訊息及已核實位置，不補畫連線。

桌機地圖約佔工作區 58%，工作區高度依視窗保留頁首、日期列及匯出列，至少 520px；1440×900 時圖卡為 748px，移除切換列後實際地圖由 508px 增至 573px。基本資料與留守、路線來源與申請、裝備／通訊／查核三區放在主工作區之後，往下捲才出現。地圖在顯示後才初始化，重新顯示或尺寸改變時依可見寬高重設視野，包含參考線及當日已定位路點。重複的路點索引與參考線來源預設收合，已定位數及參考線缺段說明保持可見；較矮視窗可在圖卡內捲動取得完整控制。部分底圖失敗提示覆於圖內，不另縮小圖面。滾輪保留頁面捲動，縮放按鈕與觸控縮放仍可用。左側時序與右側地圖共用整份計畫的路點編號；跨日與往返的同一已核實點沿用編號，點標記會選取當日對應路段。點開來源不縮小桌機地圖。

大霸新增 5 個有依據的座標：觀霧山莊、馬達拉溪登山口取自 OpenStreetMap 明名標註；九九山莊、中霸山屋、中霸坪取自官方明文座標。逐點保存查閱時間、位置依據、授權與限制，見 [大霸路點查核](research/DABA_WAYPOINTS_2026-10-25.md) 及 `data/plan-waypoints-daba.json`。只在仍關聯 `027` 且名稱精確符合明列名稱／別名時定位；白橋、3050 高地、伊澤岔口與霸基等保留未定位，不把峰頂冒充霸基。位置不同的來源不強制吸附，點間空白不補畫直線。其他範本不套用這些座標，也不按天數假裝切出精確軌跡。畫面不再提供獨立路點圖檢視；行程示意圖仍可另行匯出，往返保留每次經過，未銜接的路段保留缺口。

可在工作區直接匯入 GPX 作為本次編輯的參考圖，不離開計畫、不覆寫時間或帶入水源／宿營資訊，也不自動把範本座標配到自行匯入的軌跡。沿用 2 MB／50,000 點限制與不跨軌跡缺口連線。直接匯入的軌跡只在本次編輯暫存，離開編輯／切回路線庫或重新整理後需再匯入；若使用工具原本已匯入且同名的本機軌跡，沿用 App 記憶體。兩者均不隨草稿 JSON 保存、不上傳。地圖或來源失敗，時序、行程示意圖匯出與文字匯出仍可用。

## 行前整理與備案

編輯器上方「出發吧！」可整理目前計畫的待確認事項、返回對應日期或欄位、複製主計畫為一份獨立備案，以及比較已明確關聯的步道公告。主計畫仍使用v1草稿格式與原有儲存鍵；備案及公告比對基準使用分開的本機儲存，不自動覆寫主計畫或既有公告快照。重新查核會要求後端更新固定官方來源，仍遵守來源重試等待；資料成功取得後，由使用者明確保存比對基準。詳細操作、保存失敗保護與涵蓋範圍見[行前整理](DEPARTURE.md)。

## 儲存與匯出

草稿自動存到目前瀏覽器的 localStorage；沒有伺服器計畫 API。保存狀態只在實際寫入成功後顯示。儲存遭拒、空間不足或草稿損壞時保留錯誤提示及記憶體內容；損壞原文需先備份或明確重設，不默默覆寫。

JSON 為版本 1 的可攜草稿，匯入上限 512 KiB，最多 30 天、每天 40 路段。解析檢查型別、數值範圍、日期／時間、來源網址與識別碼；無效匯入保留原草稿。替換或清除需在介面明確確認。若欄位格式不符，JSON 仍可下載作原稿備份，但須修正後才可重新匯入。下載的 JSON／Word 可能含使用者填入的電話，分享前可自行檢查。

Word 使用 `docx` 套件在瀏覽器產生真正的 OOXML `.docx`，按匯出時才載入套件。列印版由同一份草稿與計算建立，經瀏覽器列印選「另存 PDF」；這不是已下載的 PDF。匯出包含未知欄位、待確認事項、來源附錄與公告快照，不含原範本圖片或自動醫療內容。

工作區另可下載本日白底 SVG／透明 PNG。這是依當前日別、分段、分鐘及來源產生的「路點示意・非地理軌跡」，不是底圖截圖或可導航軌跡。保留未知、來源、圖面版本及產生時間，不帶入領隊／留守電話。長名在圖面明示省略，SVG title／desc 保留完整資料。

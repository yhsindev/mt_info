# 路線資訊庫填寫方式

範本：`outputs/route-library-2026-10-25/mt_info_路線資訊庫範本.xlsx`。工作簿提供 4 張可篩選、凍結標題的表，示例路線、路點、日期與分鐘均為虛構，可直接刪除。**本輪網站尚未支援直接匯入這份 Excel**，整理完成後可依欄位轉成網站路線資料。

## 先蒐集哪些資料

先選 3–5 條自己熟悉的多日路線，每條找一篇主要紀錄與一篇不同季節的補充紀錄。先填路線名稱、方向、日別與路點順序、原文連結、作者、實走日期。時間、座標、距離不知道就留白，**不要填 0，也不要從其他方向或負重的紀錄補成同一筆**。

| 工作表 | 一列代表什麼 | 優先填寫 | 可以後補 |
| --- | --- | --- | --- |
| 路線主檔 | 一條路線的一個方向與版本 | 路線 ID、名稱、國家、山域、方向、版本、天數、起終點、主要來源 ID | 季節、技術條件、申請資訊、GPX、查核日期 |
| 分段紀錄 | 當日一段起點至終點的紀錄 | 分段紀錄 ID、路線 ID、日別、順序、起終點名稱及方向 | 路點 ID、參考／實走分鐘、各自來源 ID、休息、實走日期、負重、距離與升降 |
| 路點與資源 | 一個路點在某次紀錄的情況 | 紀錄 ID、路點 ID、關聯路線 ID、名稱、類型、來源 ID | WGS84 座標、高度、位置描述、現地日期、水況、許可、備案與查核日期 |
| 來源授權 | 一篇文章、一筆官方資料或一份提供的紀錄 | 來源 ID、原文 URL、標題、作者或單位、查閱日期 | 文章日期、實走日期、GPX／照片連結、各類素材再發布範圍與授權憑據 |

## 怎麼連接四張表

- `路線 ID` 建議用 `TW-0001`、`NZ-0001`，更名時保留 ID。不同方向或會改變分段順序的版本另建 ID，版本欄可填 `v1`、`v2`。
- `路點 ID` 建議用 `TW-POINT-0001`。同一水源跨日期保留相同路點 ID，每筆現地紀錄給不同的紀錄 ID。名稱相同不一定同一位置，沒有把握先分開。
- `來源 ID` 建議用 `SOURCE-0001`。主檔、分段及路點填來源 ID，網址與作者只需在來源授權表維護一次。
- 一個路點關聯多條路線時，在路點與資源表依路線另列，共用路點 ID。不要將多條路線 ID 塞入同一格。
- 表格有預留空列。在 Excel 最後一列按 Tab 可繼續新增，或使用「調整表格大小」。新增範圍後檢查下拉選項有否延伸。

## 時間、水源、宿營怎麼記

參考分鐘與實走分鐘各自保留來源。作者的實走總耗時若包含休息，口徑選「含休息」，不自行當成行進時間。來源未說是否含休息就選「未註明」。上河或其他出版物時間只有在來源與使用範圍可確認時才記入參考欄，不能將其他單位資料改標成上河時間。

現地紀錄日期是「哪一天走到／看到」，文章發布日期是「哪一天發文」，查閱或編輯查核日期是「哪一天讀取／核對」。日期不明就留白，不能用發文日補成現地日。水況以「紀錄有水」「紀錄乾涸」等方式描述，資料只代表該次紀錄。宿營使用狀態區分「僅有宿營紀錄」「官方設置」「需申請」「禁止宿營」，住過不代表允許宿營。床位與帳數請在備註寫清單位及適用範圍。

座標填十進位 `緯度`、`經度`，基準 WGS84。臺灣常見 TWD67／TWD97 格式不能原樣放入，請保留原檔另行轉換。沒有座標的水源也可以先整理名稱與位置描述。GPX 請保留原始檔、作者、實走日期及連結，不用手繪假軌跡補缺口。

## 向山友、山社詢問的材料

最有幫助的是原始 GPX、逐日行程／通過時間、季節與天氣、實走人數及負重、水源照片與日期、宿營點位置和許可、岔路／技術路段／撤退記錄。收集索引時可先保留連結並用自己的文字摘要，文字、GPX 與照片的公開再發布範圍分開詢問並記錄。公開可瀏覽的文章不因此視為所有素材均可再發布；對方未回覆就維持「未詢問」，不標成「已獲同意」。不要保存私人電話或隊員名單到公開路線庫。

目前最缺的是可用軌跡、可靠路點座標、按方向與負重區分的分段時間，以及附現地日期的水況／宿營記錄。先補這四種資料，比先累積上百個只有名稱的路線更有助於新版計畫通。

## GPX 取得查核（2026-10-26）

可先由開發端搜尋公開紀錄，依方向、版本、實走日期與涵蓋範圍篩選；不必全由填表者找。這次實際核對健行筆記的[玉山主峰單攻・chen anson](https://hiking.biji.co/index.php?act=gpx_detail&id=5467982&q=trail)與[雪山主峰－東峰・Kerwintu](https://hiking.biji.co/index.php?act=gpx_detail&id=932292&q=trail)：詳情頁 HTTP 200，正式 GPX 下載入口皆 HTTP 302 轉至會員登入。未登入或繞過限制，也未取得這兩份 GPX。需登入的檔案可由填表者正式下載提供，附原始網址、作者、實走日期、進出方向／版本，以及已知的素材使用範圍；取得檔案不自動視為可公開再發布。

[天池山莊檔案下載](https://tconline.forest.gov.tw/ifa/?parent_id=252)的「雲天宮入口路線 GPX」可免登入下載。本次只取一份到暫存目錄核對，內含 1 條軌跡、1 個連續段、1,129 個軌跡點，沒有 `wpt`、`rtept` 或具名稱的軌跡點。這是雲天宮入口路線，不能取代現有屯原起點範本或當作完整奇萊南華。該站[開放宣告](https://tconline.forest.gov.tw/content/?parent_id=262)要求出處並另有限制，不標為標準 OGDL；尚未將此檔放入網站。

依 [GPX 1.1 規格](https://www.topografix.com/GPX/1/1/)，命名路點與時間可缺省。每份檔案仍需檢查軌跡中斷、涵蓋區間、路點名稱／座標與來源；檔內時間不當作上河參考時間。網站目前匯入仍只作軌跡參考，不自動讀入命名路點或配對範本路點。

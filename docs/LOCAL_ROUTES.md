# 本機 GPX 路線

頁首「計畫通」內的「匯入 GPX 路線」可選擇本機檔案，在同一張 MapLibre 地圖顯示路線，並選擇篩出沿線約 3 公里內的已知座標急救設備。匯入後切至設備圖層、清除搜尋並展開清單；移除路線後恢復一般設備名錄。檔案不送至 API、不寫入瀏覽器持久儲存，重新載入即清除。

## 解析與範圍

- 接受 GPX track／route，保留各 track segment；分段之間不補連線。只有 waypoint 的檔案沒有路線，會顯示錯誤。
- 檔案上限 2 MB、50,000 個路線點；經緯度須為合法 WGS84 數字。拒絕無效 XML、DOCTYPE、ENTITY 及無效座標，名稱最多 120 字元。
- 使用既有 XML 解析套件，不載入外部資源。再次匯入失敗時保留原本的有效路線及篩選，並顯示錯誤。
- 沿線查詢採以平均緯度投影的局部平面近似，網格索引限制重複計算；超過 500,000 個索引關聯時拒絕過於複雜的檔案。約 3 公里是直線範圍，不代表可抵達路徑或地形距離。
- 沒有座標的設備不納入沿線篩選；資料未收錄不代表當地沒有設備。設備登錄與歷史配置不代表現在可用。

路線可與原生地圖圖層並看。路況、警示仍依官方適用區域閱讀，沒有用未知座標或文字區域推算沿線命中。氣象署完整 PNG 預報圖尚未地理配準，不把路線貼到圖片上，也不產生沿線雨量值。本功能不提供導航、行程時間或安全結論。

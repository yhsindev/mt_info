# mt_info 品牌符號

## 目前採用：C2 幾何步徑

2026-10-22 依使用者選擇，以 C「山稜步徑」繼續精修，同時保留目前產品的 `mt_info` 字體。三款精修及實際尺寸比較頁為 `/brand-refinement.html`；上一輪 `/brand-study.html` 保留作設計歷史，不再代表目前產品標誌。

C1 柔和版、C2 幾何版、C3 極簡版共用不對稱的主副峰，改掉原本連續鋸齒的負空間。正式版採 C2，步徑由下方進入，依「垂直 → 45° 斜向 → 垂直」兩次轉折向主峰延伸，圓頭收束。山形外緣保留高低峰的比例；固定角度的規則適用於步徑中心線，沒有宣稱山體所有斜面也採同一角度。

主符號在 64×64 畫布內，步徑沿中心線垂直方向及法線方向均為 4 單位寬，轉角以交點連接；端點半徑 2 單位。它以單一填色 `path` 形成開放至山腳的透明切口，沒有以白色筆畫覆蓋，也沒有 SVG mask、clipPath、外部圖像或字型依賴。可直接放在淺色或深色背景。

16px 版本使用獨立的 16×16 幾何，路徑加寬至 1.5px 並簡化為一個轉折，讓留白在像素格上仍能辨認。32px 保留主符號結構。瀏覽器 SVG favicon 使用 `prefers-color-scheme` 在深色分頁介面將前景改成淺色；產品頁首的白色版本不依賴該媒體查詢。

# 第一輪 A / B / C 探索（歷史）

2026-10-22 新增獨立比較頁 `/brand-study.html`，素材位於 `public/brand/`。這輪保留現有產品 logo 與 favicon，沒有增加產品主選單入口。

## 三個方向

- **A 路徑字母**：把 m 的山折與 t 的橫段接成單一路徑，末端以平緩轉折結束；名稱線索較直接。
- **B 地形指紋**：偏心、開口且不對稱的等高紋理；16px 版本改為兩層曲線，避免密紋黏合。
- **C 山稜步徑**：高低錯位的實心山稜，內切轉折步徑；16px 調整線寬與轉折，以正負空間保留輪廓。

每款均提供獨立符號、完整 `mt_info` 字標、16px／32px favicon、黑色及白色字標共 6 份 SVG，合計 18 份。16px 不是把完整符號等比例縮小，A／B／C 皆有專用小尺寸路徑。32px 沿用主符號結構。

`*-lockup.svg` 為森林綠、`*-mono.svg` 為黑色、`*-reverse.svg` 為白色；單色版本沒有以白色實體覆蓋路徑，C 以 SVG mask 留出真正透明的步徑。字標的 m、t、底線、i、n、f、o 皆以新繪向量筆畫構成，沒有依賴安裝字體或轉描字型。

## 頁面與使用方式

以暖白 `#f5f3eb`、森林綠 `#254f42` 為主；正文 18px、說明 16px、主標桌機 44px／手機 38px。三款桌機並列，窄螢幕改為直排，favicon 區依 CSS 實際 16／32px 顯示，並提供 SVG 下載連結。沒有外部字型、圖片、腳本或網路依賴，不加入口號。

頁面可透過現有本機預覽開啟：`http://127.0.0.1:5173/brand-study.html`。它是公開靜態檔案比較頁，若未來部署整個 `public/`，此頁亦會隨產品部署；`noindex` 只是搜尋引擎提示，不是存取保護。正式採用或移除比較頁，另由使用者選擇。

## 來源與後續

本輪圖形與字標為專案內原創手繪 SVG，沒有複製 Lucide 或其他 icon、現成 logo、外部照片或未明授權的素材。沒有進行商標、品牌近似或完整相似性檢索，也不宣稱已完成這些檢查。

目前各款使用同一組字標筆畫，以便比較符號差異。選定方向後可再調整字重、字距、最小尺寸、留白範圍及產品實際頁首搭配，再建立正式匯出規格；本輪不替換產品標誌。
